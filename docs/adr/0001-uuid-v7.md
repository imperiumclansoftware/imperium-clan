# ADR 0001 — UUID v7 comme clé primaire

- Statut : accepté
- Date : 2026-11-04

## Contexte
Les identifiants auto-incrémentés exposés dans l'API permettent d'énumérer les ressources et de déduire des volumes métier.

## Décision
Toute entité exposée utilise un UUID v7 (`Symfony\Component\Uid\Uuid::v7()`), mappé avec `UuidType` (`uuid` natif PostgreSQL, `BINARY(16)` MySQL). Un UUID v4 est utilisé quand la date de création ne doit pas être déductible.

## Conséquences
- Index B-tree peu fragmentés (v7 ordonné dans le temps), tri chronologique par `id`.
- Les UUID ne sont pas un contrôle d'accès : chaque ressource reste protégée par un Voter.
- Les routes valident le format (`Requirement::UUID_V7`).
